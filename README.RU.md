# ProtonShell
Легковесная оболочка для запуска веб-сайтов и веб-приложений на базе Microsoft Edge (WebView2) с поддержкой нативного API.

ProtonShell позволяет запускать веб-контент в отдельных окнах, использовать пользовательские JavaScript-скрипты и взаимодействовать с Windows через API: работать с файлами и папками, буфером обмена и системными приложениями, открывать стандартные диалоги выбора файлов и папок, а также управлять окном приложения.

ProtonShell подходит как для создания отдельных приложений на основе существующих веб-сервисов, так и для запуска собственных веб-приложений. В папке `Apps` находятся примеры готовых приложений.

## Настройка
1. Установите [Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).
2. Поместите файл `index.html` в папку с приложением или введите URL адрес, в конфигурационный файл.
3. Измените название, параметры окна, иконку, прокси, UserAgent и другие настройки, в конфигурационном файле `Config.ini`.
4. При необходимости измените иконку `exe`, с помощью [Resource Hacker](http://www.angusj.com/resourcehacker/) или укажите иконку в конфигурационном файле.

## Параметры запуска
При использовании параметров запуска чтение конфигурационного файла не используется, исключение параметр `-c` (кастомный конфигурационный файл).

`-c anotherapp.ini` - чтение конфигурационного файла, с иным названием. При использовании другие параметры запуска не используются и все параметры читаются из конфигурационного файла.

`-f index.html` - путь до html файла (относительный или полный).

`-a "https://youtube.com/tv"` - адрес веб-сайта.

`-n "My app"` - заголовок приложения.

`-i MyIcon.ico` - путь до иконки.

`-u "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:131.0) Gecko/20100101 Firefox/131.0"` - пользовательский агент (user agent).

`-s 1.js` - пользовательский скрипт (userscript).

`-w` - ширина приложения.

`-h` - высота приложения.

`-fullscreen` - полноэкранный режим.

`-p` - изменение системной прокси на заданную (формат: IP:PORT).

`-rp` - возврат прошлой системной прокси, для случаев изменения прокси на другую.

`-b 3` - стиль рамок (None = `0`, Sizeable = `1`, Single = `2`, Dialog = 3, SizeToolWin = `4`, ToolWindow = `5`).

`-t 50` - отступ сверху.

`-l 50` - отступ справа.

`-d` - включение режима отладки.

## Нативный API

Сначала подключите API ProtonShell в HTML-приложении:

```html
<script src="protonshell.js"></script>
```
### Управление приложением

| Метод                          | Описание                                         | Параметры                                                                                                             | Пример                                                                                    |
| ------------------------------ | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `app.close()`                  | Закрывает приложение.                            | -                                                                                                                     | `app.close();`                                                                            |
| `app.fullscreen()`             | Переводит окно в полноэкранный режим.            | -                                                                                                                     | `app.fullscreen();`                                                                       |
| `app.restore()`                | Восстанавливает обычный режим окна.              | -                                                                                                                     | `app.restore();`                                                                          |
| `app.setTitle(title)`          | Устанавливает заголовок окна.                    | `title` - заголовок окна.                                                                                             | `app.setTitle("My App");`                                                                 |

### Система

| Метод                          | Описание                                         | Параметры                                                                                                             | Пример                                                                                    |
| ------------------------------ | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `system.open(path, args)`      | Открывает файл, папку или URL с помощью Windows. | `path` - путь к файлу, папке или URL.<br>`args` - необязательные аргументы.                                           | `system.open("https://example.com");`                                                     |

### Работа с файлами

| Метод                          | Описание                                         | Параметры                                                                                                             | Пример                                                                                    |
| ------------------------------ | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `file.exists(path)`            | Проверяет существование файла.                   | `path` - путь к файлу.                                                                                                | `file.exists("test.txt", callback);`                                                      |
| `file.writeText(path, text)`   | Записывает текст в файл.                         | `path` - путь к файлу.<br>`text` - содержимое файла.                                                                  | `file.writeText("test.txt", "Hello", callback);`                                          |
| `file.readText(path)`          | Читает текстовый файл.                           | `path` - путь к файлу.                                                                                                | `file.readText("test.txt", callback);`                                                    |
| `file.delete(path)`            | Удаляет файл.                                    | `path` - путь к файлу.                                                                                                | `file.delete("test.txt", callback);`                                                      |

### Работа с папками

| Метод                          | Описание                                         | Параметры                                                                                                             | Пример                                                                                    |
| ------------------------------ | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `folder.list(path)`            | Возвращает содержимое папки.                     | `path` - путь к папке.                                                                                                | `folder.list("C:\\Apps", callback);`                                                      |
| `folder.exists(path)`          | Проверяет существование папки.                   | `path` - путь к папке.                                                                                                | `folder.exists("C:\\Apps", callback);`                                                    |
| `folder.create(path)`          | Создаёт папку.                                   | `path` - путь к новой папке.                                                                                          | `folder.create("C:\\Apps\\Test", callback);`                                              |
| `folder.delete(path)`          | Удаляет папку.                                   | `path` - путь к папке.                                                                                                | `folder.delete("C:\\Apps\\Test", callback);`                                              |

### Буфер обмена

| Метод                          | Описание                                         | Параметры                                                                                                             | Пример                                                                                    |
| ------------------------------ | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `clipboard.get()`              | Получает текст из буфера обмена.                 | -                                                                                                                     | `clipboard.get(callback);`                                                                |
| `clipboard.set(text)`          | Записывает текст в буфер обмена.                 | `text` - текст для копирования.                                                                                       | `clipboard.set("Hello", callback);`                                                       |

### Диалоги

| Метод                          | Описание                                         | Параметры                                                                                                             | Пример                                                                                    |
| ------------------------------ | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `dialog.openFile(options)`     | Открывает диалог выбора файла.                   | `options.title` - заголовок диалога.<br>`options.filter` - фильтр файлов.<br>`options.defaultPath` - начальная папка. | `dialog.openFile({ title: "Open file", filter: "Text files (*.txt)\|*.txt" }, callback);` |
| `dialog.saveFile(options)`     | Открывает диалог сохранения файла.               | `options.title` - заголовок диалога.<br>`options.filter` - фильтр файлов.<br>`options.defaultPath` - начальная папка. | `dialog.saveFile({ title: "Save file", filter: "Text files (*.txt)\|*.txt" }, callback);` |
| `dialog.selectFolder(options)` | Открывает диалог выбора папки.                   | `options.title` - заголовок диалога.<br>`options.allowCreateFolder` - разрешает создание новой папки.                 | `dialog.selectFolder({ title: "Select folder", allowCreateFolder: true }, callback);`     |

### Callback

Параметр callback является необязательным. Если результат вам не нужен, просто не указывайте параметр callback.

```javascript
file.readText("test.txt", function(response) {
	alert(response);
});
```

Callback получает JSON-ответ от ProtonShell.

Подробные параметры, настройки и форматы ответов смотрите в примерах в файле `index_ru.html`.

## Режим отладки
Для быстрой отладки можно включить специальный режим, в котором доступно: изменение размеров, изменение User agent, очистка всех данных. Для включения измените параметр `Debug` на `1`.
