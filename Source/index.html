ProtonShell API

Native API for HTML applications hosted by ProtonShell.

ProtonShell exposes a small native API to HTML applications. Include protonshell.js in your application to access app, system, file, folder, clipboard and dialog functions. All API operations that return a response use callbacks.
App
app.close
Closes the ProtonShell app.
app.fullscreen
Switches the ProtonShell window to fullscreen mode.
app.restore
Restores the normal window mode.
app.setTitle
Changes the window title.
System
system.open
Opens a file, application, folder or URL using the Windows shell.
Files
file.exists
Checks whether a file exists.
file.writeText
Writes text data to a file.
file.readText
Reads text data from a file.
file.delete
Deletes a file.
Folder
folder.exists
Checks whether a folder exists.
folder.list
Returns files and folders contained in a directory.
folder.create
Creates a folder.
folder.delete
Deletes a folder.
Clipboard
clipboard.get
Returns the current text from the Windows clipboard.
clipboard.set
Places text into the Windows clipboard.
Dialog
dialog.openFile
Opens a standard Windows file selection dialog.
dialog.saveFile
Opens a standard Windows save file dialog.
dialog.selectFolder
Opens a standard Windows folder selection dialog.
