ProtonShell API

Нативный API для HTML-приложений, размещённых в ProtonShell.

ProtonShell предоставляет небольшой нативный API для HTML-приложений. Подключите protonshell.js в своём приложении, чтобы получить доступ к функциям приложения, системы, файлов, папок, буфера обмена и диалоговых окон. Все операции API, возвращающие результат, используют колбэки.
Приложение
app.close
Закрывает приложение ProtonShell.
app.fullscreen
Переключает окно ProtonShell в полноэкранный режим.
app.restore
Восстанавливает обычный режим окна.
app.setTitle
Изменяет заголовок окна.
Система
system.open
Открывает файл, приложение, папку или URL через оболочку Windows.
Файлы
file.exists
Проверяет существование файла.
file.writeText
Записывает текстовые данные в файл.
file.readText
Читает текстовые данные из файла.
file.delete
Удаляет файл.
Папки
folder.exists
Проверяет существование папки.
folder.list
Возвращает файлы и папки, содержащиеся в каталоге.
folder.create
Создаёт папку.
folder.delete
Удаляет папку.
Буфер обмена
clipboard.get
Возвращает текущий текст из буфера обмена Windows.
clipboard.set
Помещает текст в буфер обмена Windows.
Диалоговые окна
dialog.openFile
Открывает стандартный диалог выбора файла Windows.
dialog.saveFile
Открывает стандартный диалог сохранения файла Windows.
dialog.selectFolder
Открывает стандартный диалог выбора папки Windows.
